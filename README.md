# Landing Page - The Odin Project

A simple, responsive landing page built as part of [The Odin Project's](https://www.theodinproject.com/) Foundations curriculum. 

**Goal:** Recreate a provided design as closely as possible using HTML and CSS.

**Live Demo:** [View Live Project](https://samdeb2000.github.io/landing-page/)

## Built With

- HTML5
- CSS3

## What I Learned

- Structuring a page with semantic HTML
- Using Flexbox to align layouts
- Using CSS variables for consistent colors 
- Making the page responsive with media queries
- Knowing when to use <div> elements to structure content
